# NexusHub


A web platform for student communities.

**Status:** In active development. The React frontend is complete and the backend is in progress.

## About

NexusHub is a student-driven community built to connect students, share opportunities, and make learning more collaborative.

From discovering hackathons, internships, and events to exploring new technologies, collaborating on projects, and connecting with like-minded people, NexusHub brings students together in one place.

Our goal is to create an environment where students can learn beyond the classroom, explore their interests, build meaningful connections, and turn ideas into action.

Learn together. Build together. Grow together. 
## Tech stack

- **Frontend:** Node.js, HTML, CSS, JavaScript
- **Backend:** In progress
- **Version control:** Git and GitHub
